# 🎨 OnePage Studio - Landing Page con Reflex

## 📌 Descripción del Proyecto

Este proyecto consiste en la recreación de una landing page profesional utilizando el framework **Reflex** con **Python**, aplicando principios de diseño web moderno, estructura organizada y componentes visuales similares a una página real de servicios tecnológicos.

La actividad fue desarrollada como parte de la **Actividad 5 - Desarrollo Web con Reflex**, cuyo objetivo principal era poner en práctica conocimientos de frontend mediante la construcción de una interfaz moderna y completamente funcional.

La landing page recreada contiene:

- Barra de navegación
- Hero section con imagen de fondo
- Sección de bienvenida
- Tarjetas informativas
- Servicios en grid
- Estadísticas
- Portfolio con imágenes
- Testimonio
- Footer

Además, se utilizaron componentes modernos como:

- Containers
- VStack
- HStack
- Grid
- Flex layouts
- Botones interactivos
- Imágenes responsivas
- Hover effects

Git se utiliza para clonar el repositorio y manejar versiones.

# 📥 Clonar el Proyecto

Abrir una terminal y ejecutar:

```bash
git clone https://github.com/ieknassss/onepage-studio-reflex.git
```

Luego entrar a la carpeta del proyecto:

```bash
cd onepage-studio-reflex
```

---

# 📦 Instalación de Dependencias

Instalar todas las dependencias necesarias utilizando Poetry:

```bash
poetry install
```

---

# 🚀 Ejecución del Proyecto

Para iniciar el servidor local de Reflex:

```bash
poetry run reflex run
```

Luego abrir en el navegador:

```text
http://localhost:3000
```

# 🧠 Proceso de Desarrollo

## 1. Planificación de la interfaz

Primero se analizó visualmente la landing page original para identificar:

- Distribución de secciones
- Colores
- Tipografía
- Espaciados
- Componentes necesarios
- Organización visual

---

## 2. Creación del entorno de trabajo

Se creó el proyecto utilizando Poetry y Reflex mediante comandos en consola.

### Creación del proyecto:

```bash
poetry new onepage_studio
```

### Instalación de Reflex:

```bash
poetry add reflex
```

### Inicialización de Reflex:

```bash
poetry run reflex init
```

---

## 3. Desarrollo de componentes

La página fue construida utilizando componentes reutilizables en Reflex.
